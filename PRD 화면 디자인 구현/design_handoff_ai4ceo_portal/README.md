# Handoff: AI4CEO Portal — 화면정의 SCR-01~09 (PRD v3.0)

## Overview
CEO·임원 대상 바이브코딩 스쿨 "AI4CEO Portal"의 9개 화면(모집 → 전형 → 결제 → 수강 → 수료 → 동문) 디자인. PRD v3.0의 화면정의 4단 구조(개요·구성·엣지케이스·데이터/권한)를 시각화한 인터랙티브 프로토타입이다. 비주얼 언어는 Apple.com 스타일(단일 Action Blue 액센트, 풀블리드 라이트/다크 타일, pill CTA, frosted 서브 nav)을 따른다.

## About the Design Files
이 번들의 파일은 **HTML로 제작된 디자인 레퍼런스**다 — 의도된 룩앤필과 동작을 보여주는 프로토타입이며, 프로덕션 코드가 아니다. 과제는 이 디자인을 **대상 코드베이스의 기존 환경**(예: Next.js — PRD의 라우트 구조 `/program`, `/portal/*`, `/alumni/*` 기준)에서 그 코드베이스의 패턴과 라이브러리로 재구현하는 것이다. 환경이 아직 없다면 Next.js(App Router) + Supabase(RLS 요구사항 존재)를 권장한다.

`AI4CEO Portal.dc.html`은 전용 런타임(`support.js`)에 의존하는 프로토타입 포맷이다. 마크업의 인라인 스타일과 아래 명세를 기준으로 재구현하라. 파일 상단의 화면 스위처/상태 칩 바(다크 바)는 프로토타입 전용 장치이며 구현 대상이 아니다.

## Fidelity
**High-fidelity.** 색·타이포·간격·라운드·인터랙션 모두 확정 의도값이다. 픽셀 수준으로 재현하되, 아래 예외는 플레이스홀더다:
- 수강료 ₩8,800,000, 입금 계좌, 전형 일정(8/3, 8/14, 8/21) — 확정 필요
- 결과물 스크린샷 영역(회색 플레이스홀더) — 실제 이미지로 교체
- 인물명(김성진, 박지연 등)·Build 제목 — 예시 데이터
